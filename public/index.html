ทดสอบความพร้อมของระบบ

รันกฎตัดสินใจและการคำนวณ lead time บนข้อมูลจำลองบนเซิร์ฟเวอร์ (ไม่ใช้ TensorFlow: ใช้ label เป็นค่า GRU จึงทดสอบเส้นทางของโค้ด ไม่ใช่ความแม่นยำของโมเดล)



  
สคริปต์

  

    
ไฟล์หน้าที่

    
loso.pyLOSO / video-independent / random split และตารางเปรียบเทียบ

    
lead_time.pyเวลาเตือนล่วงหน้าก่อนกระแทก (ms)

    
ablation.pyablation ของกฎเสริม, ความไวของ threshold, เลือก threshold แบบ LOSO

    
benchmark_edge.pylatency / FPS / RAM บน Raspberry Pi 5 หรือ Jetson

    
prepare_open_data.pyแปลงชุดข้อมูลเปิด (OmniFall, URFD) เป็น frames.csv / trials.csv

  

  
การ train GRU และการดึง landmark ต้องรันบนเครื่องของคุณ: pip install -r requirements-full.txt แล้วดู README ใน GitHub
